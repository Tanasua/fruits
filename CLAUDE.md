# Студія дитячих роликів «персонажі на чорному фоні»

Репозиторій робить відео для малюків: персонажі (фрукти, машинки, тваринки…) по одному
застрибують у кадр на чорному фоні, зупиняються в центрі, голос весело називає кожного,
і персонаж стрибає далі за кадр. Між персонажами — 1 с чорного екрана.

Перший ролик (фрукти) лежить у `fruits2d/` — це історія, нові ролики там не робимо.
Кожен новий ролик — окрема папка `videos/<назва-латиницею>/`, інструменти — у `studio/`.

## Коли користувач пише «зроби нове відео» (будь-якими словами)

Користувач прикріплює картинки й дає список назв. Далі все робиш сам, від початку до готового
mp4, без проміжних питань. Питай лише тоді, коли без відповіді далі не можна
(див. «Коли зупинитися й спитати»). Пиши користувачу українською, коротко.

### 1. Підготувати папку

- Назва папки: тема латиницею, коротко: `videos/mashynky`, `videos/tvarynky`. Якщо така вже є,
  додай номер: `videos/mashynky-2`.
- Картинки → `videos/<назва>/input/`. Порядок важливий, тож назви файли `1.png`, `2.png`, …
  у тому порядку, в якому їх прикріпили.
- Де шукати прикріплені картинки: спершу шляхи, названі в повідомленні. Якщо їх немає, шукай
  нещодавні файли: `find / -xdev -type f \( -iname '*.png' -o -iname '*.jpg' -o -iname '*.jpeg' -o -iname '*.webp' \) -mmin -180 2>/dev/null | grep -v -e '^/proc' -e node_modules -e '/videos/' -e '/fruits2d/' -e '/opt/'`.
  Перевір кожну знайдену картинку через Read, що це справді вона. Якщо картинок не знайшов,
  попроси завантажити їх у репозиторій на GitHub у папку `incoming/` (потім `git pull`)
  або дати посилання.
- Назви → `videos/<назва>/names.txt`, по одній на рядок, у тому порядку, як дав користувач.
  Назви пиши так, як їх треба вимовити (зменшувальні, як дав користувач: «кавунчик»).
- `videos/<назва>/video.json`: фраза-контекст для голосу під тему (голос вимовляє лише назву,
  а фраза задає веселу інтонацію). Приклади:
  - фрукти: `{"context": "Ура! Привіт-привіт, малята! Дивіться, хто до нас весело стрибає!"}`
  - машинки: `{"context": "Ура! Привіт-привіт, малята! Дивіться, яка машинка до нас весело їде!"}`
  - тваринки: `{"context": "Ура! Привіт-привіт, малята! Дивіться, хто до нас весело біжить!"}`
  Швидкість голосу 0.8 за замовчуванням (`"speed"` у тому ж файлі, діапазон приблизно 0.7–1.2).

### 2. Вирізати персонажів

```
python3 studio/cut.py videos/<назва>
```

- Порядок: картинки по черзі; у кожній — рядки зверху вниз, у рядку зліва направо.
  Він має збігатися з порядком назв.
- Якщо бракує scipy: `pip install scipy`.
- Якщо кількість не збіглась, скрипт малює `check/detected_*.png` з пронумерованими рамками.
  Подивись їх через Read і підбери параметри:
  - два персонажі злиплись в одну рамку → `--close 1` або `--threshold 20..30`;
  - один персонаж розпався на шматки (темні частини) → `--close 3..5`;
  - зайві дрібні рамки (іскри, текст) → `--min-area 8000` або більше.
- Обов'язково відкрий `check/cast.png` через Read і перевір, що кожна підпис-назва відповідає
  картинці (під «трактором» — трактор). Якщо порядок явно не той, не вгадуй — спитай.
- Фон має бути чорним. Якщо на картинках інший фон, скажи про це користувачу й зупинись.

### 3. Озвучка (ElevenLabs)

Ключ і голос лежать у **секретах репозиторію на GitHub** (`ELEVENLABS_API_KEY`,
`ELEVENLABS_VOICE_ID`). У сесію Claude вони не потрапляють, тому:

1. Якщо в сесії все ж є змінні `ELEVENLABS_API_KEY` і `ELEVENLABS_VOICE_ID`:
   `node studio/tts.mjs videos/<назва>`. Інакше (код виходу 3) — через GitHub Actions:
2. Закомить і запуш папку ролика (без `out/`) у поточну гілку.
3. Запусти workflow `studio-voice.yml` через GitHub MCP (`actions_run_trigger`, method
   `run_workflow`, owner `Tanasua`, repo `fruits`, ref — поточна гілка,
   inputs `{"video": "videos/<назва>"}`).
4. Чекай коміт бота «Voice clips for videos/<назва>» у гілці
   (`until git fetch -q origin <гілка> && git log origin/<гілка> -1 --format=%s | grep -q "Voice clips"; do sleep 10; done`,
   з таймаутом ~10 хв). Якщо коміту немає — подивись запуск (`actions_list`) і лог (`get_job_logs`).
5. `git pull`.

Перевір `videos/<назва>/audio/onsets.json`: у кожного кліпу пауза ≥ 250 мс (інакше початок слова
може бути обрізаний). Для тих, у кого менше, — повтори лише їх:
inputs `{"video": "...", "force": true, "only": "<id>,<id>", "seed": 100, "attempts": 10}`.

Чому так налаштовано (не міняй без причини):
- на одному слові ElevenLabs «з'їдає» перший звук, якщо слово стоїть на самому початку генерації;
  тому текст `<break time="0.5s" />Назва!`, а `mix` зсуває кліп на виміряну паузу;
- модель `eleven_multilingual_v2`: v3/v4 не підтримують `<break>`;
- stability 0.35, style 0.6 — весела жива подача; speed 0.8 — повільніше для малюків.

### 4. Зібрати ролик

```
python3 studio/make_video.py videos/<назва>
```

Запускай у фоні (run_in_background): 8-хвилинний ролик рендериться ~15 хв.
За замовчуванням ролик **довший за 8 хвилин** (`--min-sec 480`): якщо персонажів мало,
у кінець додаються повтори з початку списку. Інша тривалість — тільки якщо користувач попросив.

Скрипт сам перевіряє кадри, звук, синхрон кожної назви (±60 мс) і паузи в кліпах;
підсумок у `out/report.json`, код виходу 1, якщо є проблеми. Проблеми виправ і збери знову.
Потім відкрий `out/check_frames.png` через Read: кожен персонаж у центрі з правильним підписом.

### 5. Віддати результат

- Відео: `SendUserFile` з `videos/<назва>/out/<назва>.mp4`. У git mp4 не додаємо (`out/` в .gitignore).
- Заголовок, опис і теги українською (див. нижче) — текстом у відповіді.
- Закомить і запуш усе, крім `out/`, у поточну гілку. PR не створюй, якщо не попросили.

## Заголовок, опис, теги

**Заголовок** обов'язково містить «<Тема> чорний фон» і «українською мовою», до 100 знаків.
Зразок: `Фрукти на чорному фоні українською мовою 🍌 Вчимо назви 28 фруктів`
(для машинок: `Машинки на чорному фоні українською мовою 🚗 Вчимо назви 20 машинок`).
Дай основний варіант і два запасні.

**Опис** (зразок для фруктів, підлаштуй під тему):

```
<Тема> на чорному фоні українською мовою — спокійне розвивальне відео для малюків. Веселі <персонажі> по одному з'являються в кадрі, зупиняються в центрі, і дитина чує, як називається кожен. Між ними — коротка пауза на чорному тлі.

Контрастні яскраві картинки на чорному фоні легко роздивитися навіть найменшим. Повільний темп і чітка вимова допомагають запам'ятовувати перші слова українською.

У відео <N> <персонажів>:
<таймкоди з out/timecodes.txt>

#<тема> #чорнийфон #українськоюмовою #длямалюків #розвивальневідео #первіслова
```

N — кількість **різних** персонажів (повтори в кінці не рахуються). Таймкоди — повністю
з `out/timecodes.txt` (перший 0:00; YouTube зробить з них розділи).

**Теги**: 15–20 тегів через кому, перші — ключі із заголовка («<тема> чорний фон»,
«<тема> на чорному фоні», «<тема> українською мовою», «<тема> для малюків»…).
Ліміт YouTube — 500 знаків; теги з пробілом він бере в лапки, тож рахуй так:
`sum(len(t) + (2 if ' ' in t else 0) for t in tags) + len(tags) - 1 <= 500` — перевір python'ом.

## Коли зупинитися й спитати

- картинок не знайшов (попроси завантажити в `incoming/` на GitHub або дати посилання);
- кількість персонажів не збігається з назвами, і параметри `cut.py` не допомогли;
- назви явно не відповідають картинкам;
- фон не чорний;
- workflow озвучки падає (наприклад, секрети порожні) — перекажи помилку з логу.

## Інструменти

| Файл | Що робить |
|---|---|
| `studio/cut.py` | картинки + names.txt → assets/, cast.json, check/cast.png |
| `studio/tts.mjs` | озвучка назв (ElevenLabs), audio/*.mp3 + audio/onsets.json |
| `.github/workflows/studio-voice.yml` | те саме в GitHub Actions із секретами репозиторію |
| `studio/make_video.py` | sequence.json → рендер → звук → перевірка → out/<назва>.mp4, timecodes.txt |
| `studio/player.html` | анімація (відкривається як `studio/player.html?video=videos/<назва>`) |
| `render/render.mjs` | покадровий рендер сторінки через Playwright/Chromium → ffmpeg |

Анімація (у `studio/player.html`): 6 с три стрибки до центру, 3 с у центрі з погойдуванням
(назва звучить у момент приземлення), 6 с три стрибки за лівий край, 1 с чорного між видимими
персонажами. Кадр 1920×1080, 30 fps.
